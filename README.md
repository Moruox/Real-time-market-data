# 市场脉搏 · Real-time Market Data

轻量、无需前端构建的全球行情看板：[打开网站](https://moruox.github.io/Real-time-market-data/)。

## 功能

- 45项行情：A股与港股、亚洲、美股与欧洲指数、美股期货、国债期货及黄金。
- 市场全览将行情、走势、PE/PB、高点回撤和买点参考合并为一张表；34个股票指数支持收盘日线分析，QQQ作为ETF仅展示行情。
- 对有数据的中证指数，读取官方日频PE1（总股本）、股息率1；PB来自官方月度单张，独立标明日期和计算用股本口径。两者不能假定为同日同口径。
- 展开指数分析，可查看近252交易日走势、收盘高点回撤、200日均线、Wilder RSI14与价格区间位置。**价格位置不是估值分位**，缺少长期同口径PE序列时不计算估值分位。
- 搜索、分类、涨跌排序、本地关注列表、深浅主题和手机布局。
- 页面每30秒尝试直连行情；GitHub Actions 每15分钟尝试更新快照。日线缓存4小时，官方估值与月度单张缓存24小时；交易所时区收盘后留15分钟缓冲，未收盘日线不参与指标。
- 「场外QDII基金限额」页签自动扫描公开目录的QDII及海外股票基金，排除纯场内ETF；分为指数、主动权益、海外债券、商品、REITs、多资产/FOF，再按具体指数或投资方向筛选。境外互认基金不在此QDII目录内，目录可能有遗漏、新发和已清盘记录。
- QDII页支持基金类型、指数/投资方向、A/C/其他类别、币种、可申购筛选、已披露限额排序、搜索及分页；逐份额提供已公布净值曲线、时间范围选择、历史数据浏览和源站收益率。
- 2026-10-21扩展扫描：655个场外份额、48个指数或投资方向。数量与核验覆盖率在页面显示，随目录及抓取结果变化；失败保留最后有效数据并标注日期，缺失不伪造。
- 债基净值及数据说明板块不再展示；重要日期与来源保留在表格、详情内。界面提供金融终端风格及深浅主题，手机将同一表格的行重新排版。

## 买点参考规则

按以下顺序匹配第一项；仅使用已收盘价格指标，不混入未验证的估值综合评分，也没有收益预测。

| 状态 | 条件 |
| --- | --- |
| 深度回撤 | 较近252日最高收盘价回撤至少20% |
| 回撤观察 | 回撤至少10%，且RSI14不高于45 |
| 偏热观察 | RSI14至少70，或收盘价高于200日均线至少20% |
| 弱势观察 | 收盘价低于200日均线，且不满足前述条件 |
| 常规定投 | 前述条件均不满足 |

至少252个有效交易日才判断；日线距今超过14个自然日时暂停判断。规则未作收益优化回测，不能识别确定底部或保证收益。指数日线不含分红再投、人民币汇率、QDII费用或跟踪误差。

## 本地运行

需要 Python 3.9+、curl，测试还需 Node.js 18+。前端无第三方依赖；采集脚本使用xlrd读取官方XLS、pypdf读取官方月度PDF。

```sh
python3 -m pip install -r requirements.txt
python3 scripts/update_data.py
python3 scripts/update_qdii.py
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765/ 。不要直接双击HTML文件，浏览器会限制本地文件请求。

```sh
python3 -m unittest discover -s tests -v
node --test tests/*.test.mjs
```

## QDII限额与净值口径

限额取自天天基金的交易费率页，表示该公开渠道普通申购状态；不代表支付宝、银行或基金公司直销的额度。目录匹配的是场外指数基金、联接基金及相关指数FOF；纯场内ETF排除，标普500等权单独归类。

- 暂停或封闭状态优先于页面保留的金额。0、空值、异常大数均不当作无限额；备用申购状态表无法独立核实渠道时，显示待核实。超过2小时未更新的状态不再列为当前可申购。
- 各份额分别展示，不合计可买金额；同一系列不同份额可能共用限额，原文金额单位保留，不跨人民币和美元换算。
- 额度缓存10分钟，净值缓存6小时；GitHub Actions约每15分钟尝试更新。页面手动按钮重新读取已部署快照，不会绕过销售平台直接核发额度。
- 额度历史从首次部署后积累：观测到状态/金额变化时记录，未变化时每天留一条，最多保留180条。首次观测时间不是公告生效日期，历史不补造；部署采集端读取上次公开快照保存记录。
- 净值与限额独立保留最后有效数据。基金单位净值曲线不作分红复权；收益率引用源站公布口径，不用未复权曲线推算。QDII净值通常滞后标的市场，不能当盘中估值。
- 基金目录、限额和近60个净值日载入`data/qdii.json`，进入QDII页时才读取；完整252日历史按份额放在`data/fund-history/{code}.json`，打开详情只加载该基金；`data/qdii-history.json`作为采集端的跨次缓存，列表每页24个份额。采集器按数据种类和上次查询时间排序，优先更新额度，每轮有300秒截止时间，保留缓存并由后续运行继续补全。

## GitHub Pages

Settings → Pages → Source 选择 **GitHub Actions**。推送到`main`或手动运行工作流即可部署。无需个人Token或付费行情密钥，工作流使用内置`GITHUB_TOKEN`的`contents: read`、`pages: write`、`id-token: write`权限。

快照在部署目录生成，不回写Git历史。采集时读取上次部署的公开快照复用有效分析缓存；失败时保留最后有效数据，缺失估值不填0。网页显示实际快照时间，各行显示独立报价时间。定时任务为UTC工作日每小时07、22、37、52分，可能排队、延迟或因长期无活动停用。

## 修改指数范围

编辑`config.json`。行情源代码分别为`tencent`、`eastmoney`、`sina`。`analyze`启用股票指数分析；`historyTencent`指定日线代码，否则使用东方财富日线；`csindex`关联同一指数的官方估值文件。`zone`和`closeAfter`决定完整日线截止日期。

纳斯达克100使用`us.NDX`，纳斯达克综合使用`us.IXIC`，生物科技使用`us.NBI`；不可用综合指数或QQQ冒充纳斯达克100指数。

## 来源与口径

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 股票与现货黄金 | 腾讯财经 | 港股使用源站实时代码；美股仅正常时段，不是盘前或盘后 |
| 部分境内外指数、期货 | 东方财富 | 期货通常较昨结算，主力与当月连续可能换月 |
| 备用行情 | 新浪财经 | 仅采集端使用 |
| 指数收盘日线 | 腾讯财经、东方财富 | 剔除当地未收盘日线，取最近252个有效交易日 |
| PE1、股息率1 | 中证指数官方indicator.xls | 采用表内命名和日期，总股本口径，不与计算用股本口径混用 |
| PB | 中证指数官方factsheet.pdf | 月度计算用股本口径，日期独立；无法核实则空缺 |
| QDII基金目录 | 天天基金fundcode_search.js | 按名称、类型匹配，分开标准指数、等权变体及份额币种 |
| QDII渠道状态与限额 | 天天基金交易费率页 | 申购状态、定投状态、日限额、起点；保留查询时间与原文单位 |
| QDII净值 | 天天基金pingzhongdata | 本份额已公布净值，不以其他币种或类别代替；缺失留空 |

报价统一显示北京时间；美股按America/New_York转换并处理夏令时。海外估值无可靠同口径来源时明确暂缺；不使用不明口径的行情接口PE字段，不将20天估值数据冒充多年历史分位。

网站无登录、无账户连接、无持仓金额或额外统计服务；主题和关注项只保存在浏览器。公开接口可能限流或停用，不是交易所授权实时服务，不用于交易结算。数据与规则仅供信息参考；第三方数据权利归来源方，商业再分发需另行获得授权。

### QDII估值与买点

- 表格新增标的估值和买点两列。仅精确匹配的指数基金关联市场页分析；等权、行业、策略指数不套用宽基分析，主动基金不套用名称相似指数。
- PE/PB标注各自日期；数据缺失显示估值暂缺。债券、商品、多资产不强套股票PE/PB。当前海外估值覆盖有限，不能据此认定全部基金的便宜程度。
- 买点沿用已收盘指数的252日回撤、200日均线、RSI规则，与估值独立；未匹配或数据不足时不判断。单位净值曲线未复权；基金买点使用下面单列的复权收益参考，不把单位净值除息下跌当买点。
- 指数信号不包含基金的汇率、费用、跟踪误差，也不因暂停申购而改变；能否买入请同时看渠道状态。

### 国内黄金ETF观察

市场全览的黄金组加入华安黄金ETF（518880）；QDII页的黄金/商品分类另设研究卡，不计入场外目录或额度统计。使用ETF自身已收盘日线计算回撤、200日均线、RSI与252日区间价格位置，沿用已有买点规则。黄金不适用PE/PB，区间位置也不是估值分位；无同步IOPV时不估算实时折溢价。

### 基金复权净值买点

- 表格并列展示标的指数买点和本份额的基金净值买点，估值列仍来自底层指数；不会将净值高低当估值。
- `scripts/fund_nav.py` 使用天天基金 `Data_netWorthTrend.equityReturn` 已公布日增长率连乘重建复权收益指数，最近252个有效净值日首日归一为100。源站增长率有舍入误差，页面明确标为研究用“复权收益参考”，不是基金公司官方复权净值，也不是买入价格。
- 普通日期与单位净值涨幅交叉核对（容差0.05个百分点）；分红、拆分和折算日检查事件标记及增长率是否区别于未调整净值变动。不认识的事件、缺失或异常增长率、无效净值或超过14自然日的观测间隔会中断序列，不跨断点拼接。重复日期冲突则拒绝计算；未来记录排除。
- 连续样本不足252日时不生成基金买点；净值过期14天暂停判断。权益、指数、商品、REITs沿用现有回撤/均线/RSI规则；债券及多资产仅展示指标，不套用权益阈值。规则未作收益优化回测。
- 复权收益保持本份额币种，人民币份额含汇率影响、基金运作费用已反映在净值中，但不等于个人持仓收益；不包含用户申赎时点及申赎费用。
- 主快照保存摘要与最近60点，`qdii-history.json.adjustedFunds`保存完整252点缓存，同时生成每份额的`data/fund-history/{code}.json`供网页按需读取；重新归一后的序列整体替换，禁止跨批次按日期拼接。详情中两种曲线分别绑定历史日期滑块，且共用时间范围。
