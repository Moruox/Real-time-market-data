# 市场脉搏 · Real-time Market Data

轻量、无需构建的全球行情看板，部署于 **https://moruox.github.io/Real-time-market-data/**。

## 功能

- A股、港股、日韩台等亚洲指数，美股正常时段报价、美股期货、国债期货与黄金。
- 广发纯债A（270048）、宝盈盈润A（006242）、中信保诚稳达A（006177）最新已公布净值。
- 页面打开时每30秒尝试直连刷新；每条数据单独保留源站报价时间。
- 搜索、分类筛选、涨跌幅排序、浏览器本地关注列表、深浅主题和手机布局。
- GitHub Actions 每15分钟尝试生成快照并部署，作为直连接口失败的备用，也用于更新基金净值。任务可能排队或延迟；这不是交易所授权实时数据。
- 缺失数据不填0，失败不抹掉有效报价，旧快照不能覆盖更新的行情。基金分红单独处理，小图展示含分红再投历史。

## 本地运行

无需安装依赖。需要 Python 3.9+（含时区数据库）、curl；测试还需 Node.js 18+。

```sh
python3 scripts/update_data.py
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765/ 。直接双击 `index.html` 会受浏览器本地文件安全限制，请使用HTTP服务。

```sh
python3 -m unittest discover -s tests -v
node --test tests/quotes.test.mjs
```

## GitHub Pages

仓库 Settings → Pages → Source 选择 **GitHub Actions**。推送到 `main` 或在 Actions 中手动运行 `Refresh data and deploy Pages` 即可部署。

工作流只需仓库内置的 `GITHUB_TOKEN` 权限（`contents: read`、`pages: write`、`id-token: write`），不需要添加个人 Token 或付费行情密钥。定时任务按UTC工作日的每小时07、22、37、52分执行，不保证准时；GitHub对公开仓库长期无活动的定时任务可能自动停用。停用时可在Actions界面重新启用，网页直连行情不依赖定时任务。

快照由工作流在部署目录中生成，不回写仓库历史。仓库内 `data/quotes.json` 是初始备用样本，不代表最新部署快照；线上页面会显示实际部署快照时间。

## 修改关注范围

编辑 `config.json`。`tencent`、`eastmoney`、`sina` 分别是对应公开源代码，不同平台的同名连续合约可能存在基差、换月与时间差，不应混合比较绝对点位。

## 数据口径

| 数据 | 主要来源 | 说明 |
| --- | --- | --- |
| 股票、现货黄金 | 腾讯财经公开接口 | 港股使用源站实时代码，但仍可能延迟；美股仅展示正常时段价，非盘前/盘后成交 |
| 亚洲指数、期货 | 东方财富公开接口 | 可能存在延迟；涨跌幅沿用源站口径，期货通常比较昨结算 |
| 备用行情 | 新浪财经公开接口 | 仅快照采集端使用，网页无法直连时不伪造刷新 |
| 基金净值 | 天天基金公开数据 | 以净值日期为准，不提供当日估值预测；数据可能被修订 |

所有显示时间统一转换为北京时间，美股源站时间按 `America/New_York` 转换，自动处理夏令时。休市时保留最后报价；跨日和较早报价会明确标注。基金60个估值日图使用单位净值、累计净值推导分红后复权，不把除息误判成亏损。

## 隐私与限制

网站无登录、无账户连接、无持仓金额或个人信息。主题和关注项只保存在当前浏览器。浏览器会向公开行情服务发送普通网络请求；没有额外统计服务。

公开接口没有可用性保证，可能限流、变更或停用。数据仅供个人信息参考，不构成投资建议，不用于交易结算。批量商业再分发前应另行获得相关数据授权。本仓库没有授权第三方行情数据的再分发权。
